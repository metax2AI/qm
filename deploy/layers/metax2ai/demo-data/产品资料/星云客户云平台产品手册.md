# 星云客户云平台产品手册

版本：2026 年 8 月

## 1. 产品定位

星云客户云平台（简称"星云云"）是一套面向中小企业的客户管理、销售跟进与数据分析一体化平台。核心价值是让销售团队用一个界面管理客户、任务与合同，并用内置报表回答"今天该跟进谁"。

## 2. 产品模块

| 模块       | 说明                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 客户管理   | 客户档案、跟进记录、联系人、标签                                     |
| 销售管线   | 阶段管理（线索→初步接触→方案演示→商务谈判→签约）、金额、预计成交日期 |
| 任务与提醒 | 跟进任务自动生成、到期提醒（短信/邮件/应用内）                       |
| 合同管理   | 合同起草、审批流、归档                                               |
| 数据报表   | 管线金额、超期跟进清单、赢单率、团队排名                             |
| AI 助手    | 基于企业资料的问答、待办提取、回复草稿、每日经营摘要                 |

## 3. 版本与价格

### 3.1 版本目录

| 版本         | 价格       | 适用                   |
| ------------ | ---------- | ---------------------- |
| 标准版       | 5 万元/年  | 10 人以下团队          |
| 专业版       | 12 万元/年 | 10–50 人团队           |
| 私有化部署版 | 30 万元起  | 有数据本地化要求的客户 |

### 3.2 折扣与审批

报价规则见《销售跟进制度》3.1 节：标准版折扣下限 8 折，专业版及以下 7 折；任何低于下限的价格需销售总监审批。

## 4. 实施与验收

### 4.1 实施周期

- 标准/专业版：实施周期 2–4 周，含数据迁移工具。
- 私有化部署版：实施周期 4–8 周，包含数据迁移工具与现场实施。
- 免费试用：专业版 14 天试用，不限功能。

### 4.2 验收条款

- 标准/专业版：以功能清单逐项验收，客户签署验收单后进入服务期。
- 私有化部署版：验收标准见合同附件 A，包含数据迁移完整性、性能指标与培训交付三部分。
- 验收争议由双方项目经理在 5 个工作日内书面确认，逾期视为通过。
