# 演示数据说明

本目录是 M2 Web 企业 MVP 的**脱敏演示数据**，不含任何真实客户信息。数据互相自洽，可直接用于演示"客户跟进与经营摘要"Skill 的完整流程。

## 文件清单

| 文件 | 用途 |
| ---- | ---- |
| 客户跟进表.csv | 10 个客户档案，含阶段、金额、跟进日期、负责人 |
| 会议纪要/2026-08-06-重点客户跟进会.md | 与跟进表对应的行动项 |
| 产品资料/星云客户云平台产品手册.md | 产品能力、价格、实施周期 |
| 企业制度/销售跟进制度.md | 跟进频率、折扣、账期、审批边界 |

## 演示前准备

- 把 `客户跟进表.csv` 的"下次跟进日期"改为演示当天，确保有"今天到期"和"已超期"的客户（当前示例基于 2026-08-07）。
- 在 Web UI 登录后上传本目录全部文件（以个人 scope 上传即可）。
- 向 Agent 提问，例如：
  - "今天最重要的客户是哪些，为什么？"
  - "列出所有已经超期没跟进的客户。"
  - "从这个会议纪要里提取待办。"
  - "帮华宇精密制造起草一封回复合同条款的邮件草稿。"
  - "生成今天的经营摘要。"

## 数据自洽性

- 跟进表与纪要互相引用：金桥建设集团"已超期"、绿源食品"账期异议"、华宇精密制造"法务条款"在纪要中有对应行动项。
- 产品手册与制度的折扣/账期规则一致，Agent 起草报价或邮件时可引用两处。
- 表内列名为中文，用于验证 Skill 的列名容错解析。
